## The entry

**Hoverboss** — one word for the boss who never quite leaves your desk, hovering over your shoulder while you work.

## How it works

`main.ts` writes the single-word entry deterministically to `/output/entry.txt`. No input, no network, no randomness — every run produces the exact same 9-character file.

Run it with Node 22.18+:

```sh
node main.ts
```
